# 广东高考知识地图

> 本文件说明课程边界和拓扑规则。`学习资料/知识节点.json` 是 knowledgeId、前置边和通过标准的唯一目录。

## 广东新高考模式

- 语文、数学、英语统一必考。
- 首选科目是物理或历史。
- 再选科目从化学、生物、政治、地理中选两科。
- 学员实际备考六科。

## 教学单元规则

每个知识节点只表示一个能独立复习的关系或能力。

知识节点不得使用整章、整册、题型名称或错题编号。

稳定 ID 格式是：

```text
科目::模块::知识点
```

示例：

- `数学::初高衔接::分式四则运算`
- `数学::函数::输入对应输出`
- `英语::从句::定语从句的修饰关系`
- `物理::牛顿定律::合力与加速度关系`

ID 不包含日期、题号、难度、复习状态或掌握状态。

正式 ID 一经使用就不可直接删除或改名。显示措辞变化时保留 ID。

如果必须替换 ID，在 `知识节点.json` 的 `aliases` 中登记“旧 ID → 新 ID”。扩展会迁移计划、任务和知识状态。

## 前置关系规则

`知识节点.json` 中的 `prerequisites` 只登记直接前置节点。

确认前置缺口时，必须使用目录中的直接前置边。

不能把当前要学习的目标关系改名为前置知识。

每个节点必须包含至少一个可观察通过标准。

## 课程覆盖与版别基线

当前目录是完整高中课程清单（必修 + 选择性必修），并附初中前置骨干。
共 575 个节点：高中 475 个，初中前置骨干 100 个（数学、物理、化学、生物、英语）。

每册教材的目录项 → 节点覆盖关系登记在 `test/fixtures/coverage/`（覆盖矩阵），由 `test/coverage.test.ts` 回归校验：高中册不允许有未覆盖的真实教学内容（矩阵中不得残留「缺口」行），目录节点必须全部被矩阵行引用或登记豁免理由。

版别基线（目录取材自 TapXWorld/ChinaTextbook 教材电子版）：

- 语文、历史、政治：统编版。
- 数学：人教 A 版。
- 物理：粤教版（广东主流）；初中各科均为人教版。
- 化学、生物、地理、英语：人教版。
- 节点是关系和能力，版别只影响册次顺序，不改变前置拓扑。

## 扩展目录的流程

教材或校内进度出现未登记内容时，先做备课，不直接开始教学。

新增节点时：

1. 确认内容属于广东范围和校内进度。
2. 把内容拆成一个可独立复习的关系或能力。
3. 选择稳定的科目、模块和名称。
4. 登记直接前置节点。
5. 写出可观察通过标准。
6. 同步更新覆盖矩阵（`test/fixtures/coverage/`）并运行目录校验与覆盖测试。
7. 再把节点加入两周计划。

分发包模板目录版本升级时，已安装的消费端不会自动获得新节点（数据件只首次复制）。
在消费端工作目录执行分发包的 `scripts/migrate-catalog.mjs` 做追加式迁移：

- 只追加缺失节点，保留本地演化节点内容，不覆盖。
- 模板别名（如旧模块「中国史」）会把消费端旧 ID 节点迁移到新 ID 并登记引用。
- 同一 ID 内容不一致时迁移失败并写备份，由操作者人工处置。
- 幂等：已迁移过的目录再次运行不改任何内容。
