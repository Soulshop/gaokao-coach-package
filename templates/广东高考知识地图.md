# 广东高考知识地图

> 本文件说明课程边界和拓扑规则。`学习资料/知识节点.json` 是 knowledgeId、前置边和通过标准的唯一目录。

## 广东新高考模式

- 语文、数学、英语统一必考。
- 首选科目是物理或历史。
- 再选科目从化学、生物、政治、地理中选两科。
- 学员实际备考六科。

## 教学单元规则

每个知识节点只表示一个能独立复习的关系或能力。

知识节点不得使用整章、整册、题型名称或错题编号。

稳定 ID 格式是：

```text
科目::模块::知识点
```

示例：

- `数学::初高衔接::分式四则运算`
- `数学::函数::输入对应输出`
- `英语::从句::定语从句的修饰关系`
- `物理::牛顿定律::合力与加速度关系`

ID 不包含日期、题号、难度、复习状态或掌握状态。

正式 ID 一经使用就不可直接删除或改名。显示措辞变化时保留 ID。

如果必须替换 ID，在 `知识节点.json` 的 `aliases` 中登记“旧 ID → 新 ID”。扩展会迁移计划、任务和知识状态。

## 前置关系规则

`知识节点.json` 中的 `prerequisites` 只登记直接前置节点。

确认前置缺口时，必须使用目录中的直接前置边。

不能把当前要学习的目标关系改名为前置知识。

每个节点必须包含至少一个可观察通过标准。

## 课程覆盖与版别基线

当前目录是完整高中课程清单（必修 + 选择性必修），并附初中前置骨干。
共 426 个节点：高中 334 个，初中前置骨干 92 个（数学、物理、化学、生物、英语）。

版别基线（目录取材自 TapXWorld/ChinaTextbook 教材电子版）：

- 语文、历史、政治：统编版。
- 数学：人教 A 版。
- 物理：粤教版（广东主流）；初中各科均为人教版。
- 化学、生物、地理、英语：人教版。
- 节点是关系和能力，版别只影响册次顺序，不改变前置拓扑。

各科模块分布（模块×节点数）：

### 语文（31）

现代文×8、文言文×7、作文×6、语言运用×6、古诗×3、整本书阅读×1。

### 数学（89）

集合与逻辑、函数、二次关系、指数对数、三角、向量、复数、数列、不等式、立体几何、解析几何、导数、计数原理、概率、统计、成对数据（高中 49）；初高衔接×7；初中数与式、方程与不等式、函数、几何、统计概率（初中 33）。

高一启动主轴不变：

```text
有理数运算
  ├─> 整式运算 ─> 一元一次方程
  ├─> 分式意义 ─> 分式通分 ─> 分式四则运算
  └─> 不等式同解变形

整式运算 ─> 输入对应输出 ─> 定义域或单调性
整式运算 ─> 一元二次方程 ─> 二次函数图像与参数
二次函数图像与参数 ─> 函数与方程 ─> 函数与不等式
```

每个高中主轴节点有更深的初中前置链可回溯，例如：

```text
初中二次根式与幂运算 ─> 指数与幂运算 ─> 指数函数
锐角三角函数 ─> 三角函数定义与诱导公式 ─> 三角函数图像与性质
```

## 扩展目录的流程

教材或校内进度出现未登记内容时，先做备课，不直接开始教学。

新增节点时：

1. 确认内容属于广东范围和校内进度。
2. 把内容拆成一个可独立复习的关系或能力。
3. 选择稳定的科目、模块和名称。
4. 登记直接前置节点。
5. 写出可观察通过标准。
6. 运行目录校验测试。
7. 再把节点加入两周计划。
