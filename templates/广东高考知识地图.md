# 广东高考知识地图

> 本文件说明课程边界和拓扑规则。`学习资料/知识节点.json` 是 knowledgeId、前置边和通过标准的唯一目录。

## 广东新高考模式

- 语文、数学、英语统一必考。
- 首选科目是物理或历史。
- 再选科目从化学、生物、政治、地理中选两科。
- 学员实际备考六科。

## 教学单元规则

每个知识节点只表示一个能独立复习的关系或能力。

知识节点不得使用整章、整册、题型名称或错题编号。

稳定 ID 格式是：

```text
科目::模块::知识点
```

示例：

- `数学::初高衔接::分式四则运算`
- `数学::函数::输入对应输出`
- `英语::从句::定语从句的修饰关系`
- `物理::牛顿定律::合力与加速度关系`

ID 不包含日期、题号、难度、复习状态或掌握状态。

正式 ID 一经使用就不可直接删除或改名。显示措辞变化时保留 ID。

如果必须替换 ID，在 `知识节点.json` 的 `aliases` 中登记“旧 ID → 新 ID”。扩展会迁移计划、任务和知识状态。

## 前置关系规则

`知识节点.json` 中的 `prerequisites` 只登记直接前置节点。

确认前置缺口时，必须使用目录中的直接前置边。

不能把当前要学习的目标关系改名为前置知识。

每个节点必须包含至少一个可观察通过标准。

## 广东高一启动范围

当前目录是启动目录，不是完整高中课程清单。

### 数学

- 初高衔接：有理数、整式、分式、方程和不等式。
- 函数：输入对应输出、定义域和单调性。
- 二次关系：方程、函数图像、函数与方程、函数与不等式。

数学启动主轴：

```text
有理数运算
  ├─> 整式运算 ─> 一元一次方程
  ├─> 分式意义 ─> 分式通分 ─> 分式四则运算
  └─> 不等式同解变形

整式运算 ─> 输入对应输出 ─> 定义域或单调性
整式运算 ─> 一元二次方程 ─> 二次函数图像与参数
二次函数图像与参数 ─> 函数与方程 ─> 函数与不等式
```

### 英语

- 拼读和句中词义。
- 主语、谓语和五大基本句型。
- 一般时态和现在完成时。
- 定语从句和名词性从句的核心关系。

### 语文

- 文言实词、虚词、词类活用和特殊句式。
- 现代文信息定位和论证关系。
- 古诗意象与情感联系。
- 作文立意和论证结构。

### 物理

- 单位、量纲、标量和矢量。
- 参考系、速度变化率和匀变速关系。
- 受力图、力的合成分解和牛顿定律。

### 历史

- 时空定位。
- 史料事实与观点。
- 因果解释与证据。
- 中国古代史阶段联系和近代史主线。

### 化学

- 物质分类。
- 物质的量、摩尔质量和浓度。
- 离子反应、氧化还原和周期律基础关系。

### 生物

- 细胞结构与功能。
- 分子结构与生命功能。
- 光合作用、细胞呼吸及两者联系。

### 政治

- 概念条件与边界。
- 观点与材料证据。
- 中国特色社会主义主线和经济主体关系。

### 地理

- 空间定位和地图信息。
- 地球运动、大气、水循环和区位条件。

## 扩展目录的流程

教材或校内进度出现未登记内容时，先做备课，不直接开始教学。

新增节点时：

1. 确认内容属于广东范围和校内进度。
2. 把内容拆成一个可独立复习的关系或能力。
3. 选择稳定的科目、模块和名称。
4. 登记直接前置节点。
5. 写出可观察通过标准。
6. 运行目录校验测试。
7. 再把节点加入两周计划。
